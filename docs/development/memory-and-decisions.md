# 记忆、章程与判断

## 信任层

知君区分三种长期状态：

- 对话记录：用户和助手的原始交流及其来源回执。
- 工作理解：系统提出但尚未由用户确认的候选，只能带不确定语气使用。
- 已确认理解：用户确认或修订后的内容，可以按单独授权进入其他用途。

用户可以确认、部分确认、限定情境、忽略、修订或撤回理解。系统推测、资料观察、用户原话和理想方向不能混为同一种事实；被纠正的内容保留审计并防止无依据回流。

## 低打扰整理

记忆整理默认只提出少量具有长期价值的候选。一次性活动细节、AI 辅助表达和空泛推测不应直接成为稳定人格理解。事件细节可以先合并到本地小结，只有用户主动保存后才成为有来源的情境记录。

记忆候选、校准和小结共享有限注意位，处理一项后不自动轮播下一项，也不抢输入焦点。用户选择“仅在我要求时整理”后，普通对话不自动排队新的理解任务；显式“请记住”仍需用户核对。

## 自我校准

校准用于用新经历检查旧理解，而不是训练第二个个人模型或给用户打分。事前观察与事后结果分开保存；保存对照不会自动改写本体，只有用户明确应用修订时才通过统一状态入口替代旧理解。

校准记录保留原理解、判断、证据和版本。不同情境、阶段、愿望和长期倾向必须分开处理，不能因为一次结果就推断终身原则。

## 人生章程与判断

人生章程由用户建立、编辑和发布，系统可以提出建议但不能自行改变。章程中的挑战方式、边界和静默领域影响模型行为，不等于资料外发授权。

判断流程把当时的选择、理由、把握和预期与之后的真实结果、复盘分开。判断草稿只接受有来源的内容，必须由用户确认后才写入判断簿；复盘经验可以形成候选理解，但不会自动晋升为原则。

## 来源与权限

- 保存理解、章程、判断或小结不自动授予在线模型使用权限。
- 任何派生内容都继承原会话、资料、判断或成果的来源限制。
- 删除、撤回、版本变化或来源链缺失后，旧授权失效或保守停止使用。
- Context Pack 和其他 Agent 只能读取用户明确允许带走、已确认且非受限的投影。
- 本地专用任务不会静默切换到在线；NPU-only 是否成立由 CentaurOS 运行时和审计确认。
