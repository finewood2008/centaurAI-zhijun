基线：桌面 `eebd58b`，公司盒 DE `9fdff00`。用户反馈仍慢，不能用上一轮请求批次改善替代本轮验收。

- [x] 主 agent：完成图标集成审核、针对性回归、公司盒重连、文档与远程提交。任何部署须使用独立版本目录并保留当前运行版本回退。

依赖与边界：桌面仍通过主进程 → Consumer SDK → Agent → DE 的受控 HTTP 通道。当前每项业务读取采用 start/poll 两步，不擅改签名路由或响应合同。磁盘全库扫描成本另有证据，尚未纳入本次最小补丁。

验证须覆盖：ready 缓存期限、未完成/错误不缓存、并行请求合并、过期响应不跨连接回填、引导更新失效；poll 通知竞态、并行读取、取消/吊销、SSE 首块；PNG 外缘真实 alpha 与实际 Dock 显示。记录合成基准和真机观测的不同范围，不宣称未测的端到端耗时。

新增主 agent 任务：首屏五项读取需要十次 start/poll 请求，另有初始 context 与控制请求。短时 token 桶由 8 调为 12，使正常首屏不因本地补充 token 等待 600 ms 阶梯；native 同时执行上限仍为 8，业务上限 7，滚动 60 秒总量 100 / 业务 92、会话 1000、上传预留与未知写入策略不变。验收增加五项读取与心跳组合，并复验滚动窗口、会话和上传配额。

### 对话任务风暴与发送参数修复（0907 最终追加）

现场的“读取请求过多”来自任务槽耗尽，而不是 HTTP 协议没有生效。桌面业务仍经 Direct HTTP 的 start/poll 通道访问盒子；当时同一工作区已有 1024 个持久任务，其中大量读取由三个常驻刷新源制造：附件状态、画像授权状态及路由设置。现已分别改为仅在过渡态轮询、完成或空列表后停止、失败指数退避，并移除路由设置每 10 秒无条件读取。页面进入、打开设置、消息完成和用户显式操作仍会主动刷新。最新桌面构建在对话页空闲观察 15 秒期间，盒端路由任务计数保持 `93 → 93`。

盒端容量补丁在满额创建新任务前，只回收完成超过一小时且明确标记 `mutating=false` 的读取任务，按最旧顺序降到 75% 低水位。真实工作区首次从 `1024` 降至 `770`；8 个当时已有的写任务全部保留。后续现场操作增加了写任务，补丁仍只回收读取，不能把写入墓碑或未知标记当作可删除对象。

“请求参数不符合要求”的根因位于桌面传输适配层：路由预览和正式消息按业务合同共用 domain `body.requestId`，旧代码又把它作为 Gateway job `requestId`，第二个不同 operation 因幂等冲突在主进程内被拒绝，正式 `/messages` 没有到达盒子。现在每个 Gateway 传输任务生成独立随机 ID；业务正文中的 domain ID 保持不变，用于预览与正式消息关联。声明了 `Idempotency-Key` 的确认类操作仍按 catalog 使用稳定传输 ID。

真机使用公司盒 `AMD-A2A-248` 复测：同一业务 ID 的预览与正式消息均成功，问题“你是哪个模型”收到盒端模型完整回复，界面没有再出现参数错误或 429。前端全量 **78/78**、Shell 全量 **143/143**、Electron E2E **4/4**、产品导航 E2E 与 Desktop 构建通过。

账号登录态另设固定 7 天本地截止时间，凭据只保存在系统加密存储；普通关闭应用会保留，显式退出会先清除本地凭据。重启真机应用两次均自动恢复账号并进入设备选择页。`SESSION_EXPIRED` 和已经确认关闭的 `CONNECTIVITY_SESSION_EXPIRED` 都会清除账号、设备列表和加密登录记录，由现有桌面入口立即显示完整登录页。普通 Direct 建连失败、请求超时和权限拒绝仍保留账号，允许重新选择盒子。Access Token、Connectivity ticket、P2P session、逐请求证明和 workspace lease 继续使用各自短周期。

### “我的本体”按视图加载（0907 追加）

默认摘要原先同时发起 stats、当前分区 claims 和摘要全量 claims 三个业务任务，实际模板只消费摘要全量 claims。每项至少经过一次 start 和一次 poll，因此默认页面最低产生 6 次 SDK HTTP；导航提示缓存未命中时最低 8 次。

现按当前视图加载：摘要只取摘要 claims，全景才补 stats，列表/inbox 才取分区 claims 与 stats；成功返回空数组也记为已加载，视图来回切换不重复请求。默认业务任务由 3 降为 1，最低 SDK HTTP 由 6 降为 2。真实应用两次重启、生产登录并连接公司 `AMD-A2A-248` 后，顶部显示名称，自动化从“今日来信”进入“我的本体”分别约 658 ms、763 ms 出现摘要内容；观测包含 UI 自动化开销，不定义 SLA。详细调用边界见[接口去向审计](DESKTOP-API-ROUTING-AUDIT-0907.md)。
