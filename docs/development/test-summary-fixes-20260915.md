## 现场 S1 证据与修复边界

公司盒新一轮消息操作 `f796ba12038aa98db0bd629a491edb3f` 135 个网关事件后以 `WORKSPACE_OPERATION_FAILED` 结束；同类错误在容量补丁之前也存在。普通本体、资料读取已成功，不是旧 1024 条准入问题。

只读核查确认：assistant 在对话库中已是 complete；网关最后收到的是最终 provenance，未收到 extraction / message_done。现场没有保留底层异常栈，因此不能把中转站、后台 429 或某个具体错误码定为此次唯一根因。

新增真实签名 worker + 本地 HTTP 能力回调回归，注入“后台登记被拒绝”“回调响应契约错误”，复现此前的正文后断流。修复将回答完成与后续整理入队结果分开：登记失败留下 failed 任务及原 payload，不允许自动执行；手动恢复仍需重新登记和验证权限。相同 requestId 重放不重复消息、模型请求或后台登记。新异常保留 CapabilityError 类型与 HTTP 状态，其他调用方不会因此退化成泛化 500。数据库写入本身失败、没有 jobId 时，不承诺存在可恢复任务。

## 各项实现

| 项目 | 调整 |
| --- | --- |
| A1 | 输入框加号菜单支持移出、外部点击、Esc 关闭，不清空草稿。 |
| A2 | 情景卡替换整段输入、正确切换商量模式，不自动发送。 |
| A3 | “换个说法”“先放一放”互斥替换，保留一次撤销和输入来源。 |
| A4 | 麦克风位于发送/停止左侧，窄屏换行，不覆盖缩放手柄。 |
| B1 | “记下来”解析到同一对话最近的用户事实原话，生成待核对候选；保留证据、去重及手动记忆/外发权限。 |
| B2 | 补充完整文件名与明确项目主题检索触发，展示查询和来源范围；原材料不依赖知识卡片，片段仍需用户选用。 |
| B3 | 空白会话提供事情入口，按需且单次创建会话，补首轮辅助信息加载。 |
| B4 | 明确换题或可辨别的不相关新请求暂停旧事情参考；新建/关联/成果保存校验绑定修订，阻止串写旧事情。 |
| B5 | 列表增加软回收入口，复用影响预览、依赖决策、确认凭证及版本校验；不提供永久删除。 |
| B6 | 五个资料子页面统一返回“资料与边界”，保留路由离开保护。 |

限制：B4 使用保守的明确主题规则，未知或模糊主题不保证自动识别；保留用户主动换题入口。B2 当前 Data Engine 返回不足以区分“未索引”和“无命中”，客户端不会伪造索引状态，服务或授权错误也不等同于零结果。

## 验证与发布范围

- 后端 18 个相关模块通过隔离测试入口：296 项（含子测试），0 失败；随后增加异常类型/安全状态兼容测试，S1 模块 4 项通过。
- 最初将多个模块放在同一进程的回归出现路由/配置单例污染；使用仓库规定的 `scripts/run_tests.py --isolated-modules` 后，同一组模块全部通过。未为通过测试而放宽 CSRF 或授权。
- 最终前端 `test:all` 218/218 通过，类型检查和 `build:desktop` 通过；保留现有 taskRouting 混合静态/动态导入构建警告。
- 补充隔离验证记忆队列、策略、候选准入、worker 端口及事情竞争 5 个模块，165 项（含子测试）通过；与前述 18 个模块有重复，不合并冒充独立测试数。
- Composer 使用真实 SFC 配合合成语音 API，验证宽屏/390px、桌面语音/WebSpeech 四种组合；资料页合成 API 浏览器回归覆盖 8 种宽度，并验证预览、取消及软回收。主代理复看窄屏截图。
- 这些是本地自动化与合成接口验证，不是安装后的 Electron / 真实盒端 / 外部模型端到端验收。本轮未发布新安装包，也未把这些业务修改部署到公司盒子；原先容量补丁部署状态独立记录。
