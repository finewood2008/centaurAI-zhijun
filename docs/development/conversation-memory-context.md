# 对话读取本体与章程（2026-09-04）

## 行为

- 从「我的本体 → 人生章程 → 通过对话修改」创建会话时，显式保存 `taskContext: charter`。`routing_tasks` 只存枚举，不保存用户原话，不代表任何外发授权。旧会话不回填。
- 章程查询逐栏读取当前正式版本，包含空字段。空字段同样使用既有版本化 `charter` 来源和授权检查。未读取、未填写、尚未确认不同义，默认跳过权限不足的字段不会说它们未填写。
- 章程核对不混入一般本体目标；用户当前自足的新问题或明确换题优先于入口任务。短追问只继承实际允许的近期话题，不使用被 cutoff、未完成、来源失效或未授权历史作为检索线索。
- 当前章程状态在模型发送前再次核对版本。历史判断使用的不可变章程版本不受该指针检查影响。
- 本体检索结合当前问题、明确追问和最近安全话题。自我概览按分区覆盖已确认记录；普通问题只带相关的有界候选，并重新检查设备范围、生命周期和授权。
- 追问可重新读取最近助手回复明确记录的直接 Claim 依据，不把其递归祖先里的所有旧记录当成当前主题。

## 有界检索

`memory_retrieval.py` 不调用小模型解释意图。使用词面与有限同义主题召回；仅在本地 embedding 已加载时复用，最多编码 32 个短片段，使用 256 项缓存。不触发模型加载、下载或外部服务，不宣称是全库语义索引。相关候选通过阈值后，长期认同的贴合度参与小幅排序。

## 回执与兼容

新增可选 `provenance.memoryContext`：intent、directCount、inheritedCount、excludedCount、searched、status、charterChecked、charterComplete。

直接与继承以 Claim ID 去重，直接优先；继承指实际纳入的近期历史来源，不等于重新阅读原始记录。只有完整读取七栏状态才显示「已核对人生章程第 N 版」。旧回执缺少新字段时使用保守描述，不批量重写。
