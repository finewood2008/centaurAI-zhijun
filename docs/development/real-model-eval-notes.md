# 真实模型评测 · 三轮对比（DeepSeek，2026-09-02）

`docs/development/real-model-eval.md` 由 `scripts/real_model_session.py` 每次覆盖；这里记三轮的差异与结论。密钥只走环境变量，不进仓库。

| 项 | 第一轮（旧提示词，v4-pro 全程） | 第二轮（良师内核，pro 回复 / flash 后台） | 第三轮（+ 思考开关、措辞修正） |
|---|---|---|---|
| 建档抽取 | 0 条（脚本没等后台任务） | 12 条，7 条直接确认，实体 3 | 18 条，12 条直接确认，实体 6（含 2 条噪音：用户本人、「5人小组」） |
| 第一次观察 | 无 | 有，「对吗？」结尾 | 有，把两件事连起来 |
| 商量草稿 | 空（推理把预算吃光） | SSE 排队，脚本未取 | 字段齐全；用户只说「倾向」时 choice 留空、leaning 记录 |
| 商量回复 | 五段但空泛 | 连过去、给看法带前提 | 同上，并追问「最晚哪一天启动备选」 |
| 日常回复 | 复述 + 标签 | 复述 + 标签；一轮被截断 | 不复述，直接接住并连到过去；未截断 |
| 每轮耗时 | 中位 8s / 最长 28.5s | 中位 13s / 最长 25.5s | 中位 2.1s / 最长 19.4s |
| 模型自称「已记进判断簿」 | 有 | 有（「我记进判断簿」） | 无 |

结论与遗留：
- 推理型模型必须区分强度：简短回复与后台 JSON 关思考，深聊 / 商量 / 第一次观察开思考并放宽预算（`ZHIJUN_OPENAI_THINKING`）。
- 抽取粒度偏细（同一句拆成 3 条），整合器的合并提案在这轮没触发（相似度阈值偏高），待用更多轮对话验证。
- 「把周末还给家里」被降成推测：愿望判定只看了引用片段，改为看引用所在整句（本轮修）。
- 实体噪音：用户本人、临时团体不该成实体（本轮在提示词里加规则）。
- 12 轮真实对话花费在 DeepSeek 上可忽略；评测脚本与端到端脚本都占 8618 端口，不能同时跑。
