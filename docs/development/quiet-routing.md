# 低干扰授权与记住处理方式

2026-09-04。沿用现有统一路由和逐来源外发检查，不放宽权限，不改写原始记录。

- 自动检索到的旧历史、理解或章程，其来源链失效、版本不匹配时暂停引用，不把它当成可追加授权的项目反复弹窗。回答旁显示轻提示，具体未纳入原因可展开查看。
- 新增“模型与授权 → 记住资料受限时的处理方式”。默认关闭，由用户主动保存。开启后可选择：跳过受限参考继续在线（保留已授权资料），或需要受限参考时本轮使用本地模型。正常对话仍在线。
- 该偏好绑定设备作用域和当前在线服务，持续到关闭或修改；服务变化后需重新选择。偏好不是外发授权，原有默认授权、撤销、文件授权独立生效。
- 明确选用的文件、回访判断、AI 辅助输入自身携带的来源限制不会被“跳过”设置剥离。仍无法安全处理时保留必要确认/错误；后台任务缺权限继续暂停。
- 本地模型不可用时保留输入/消息并提示，不自动改用在线。省略内容时提示模型不能装作理解；关键内容缺失必须先澄清。
