## 验收

- 仅收到正式消息 ID 后的传输异常可自动核对，最多 3 次 GET、总时限 8 秒；绝不重发 POST。
- 只接纳当前会话、当前工作区、同一 assistant ID、replyTo 和 requestId 的已保存完整正文；未确认、无正文或不匹配不能改成成功。
- 取消、换盒、换会话和注销后不得写回旧状态。
- 核对无结果时保留部分正文，空正文有明确提示；支持用户只读核对，和重新调用模型区分。
- 业务 error/授权拒绝不冒充传输失败而自动恢复。
- 校验失败的事件页不得部分提交读取游标、字节计数或 blob 句柄。
