# 安装后登录恢复与失效会话处理

## 计划

截图为 ACCOUNT_SERVICE_UNAVAILABLE，重新登录后恢复；不能仅据此断言 refresh token 过期。现有 SESSION_EXPIRED 已清除公开账号并显示登录界面，本轮补响应分类和失败空态。

- consumer-client.cjs：非 JSON 的 HTTP 401 仍识别为认证拒绝；受保护接口已知会话失效机器码进入单次协调刷新，客户端撤销/明确无活动会话终止登录；网络、429、5xx、未知403不误退出。
- desktop 登录/设备选择页面：读取失败不显示“无绑定盒子”的成功空态；保持可操作重试与登录恢复。
- 验收：过期令牌一次刷新成功仍可使用；刷新明确拒绝回登录且清除旧会话；撤销不能循环刷新；网络错误保留会话；晚到结果不得覆盖新登录；前端和宿主回归通过。
- 仅修改知君客户端及对应测试，不修改账号服务、盒端、用户绑定或现有生产登录数据。打包发布另行记录，不把源码修改当作已安装修复。

## 实施与验证

以上客户端改动已完成。明确 `hasActiveSession=false` 清除会话；字段缺失仍拒绝访问，但不推定登录失效。恢复凭证统一使用现有 SDK 的单次协调刷新，不新增轮询。

服务暂不可用时提供“重新获取盒子”和“重新登录”；设备列表为空且读取失败时不再显示“暂无已完成授权的盒子”。会话明确失效后，runtime 清除公开账号，界面直接显示登录表单。

- Shell 全量测试：335 通过，1 项 Windows 专用测试在 macOS 跳过，0 失败。
- 前端 desktop 测试：54 通过；包含实际 SFC setup/reactive 状态测试，非真实 Electron 渲染验证。
- 前端 `vue-tsc -b` 通过。
- 覆盖恢复后认证失败、刷新成功与失败、撤销无刷新循环、明确无活动会话、网络/503/429/403 不清除凭证及既有并发刷新、晚到响应隔离。
