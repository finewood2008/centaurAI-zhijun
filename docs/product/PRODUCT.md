# 知君产品定义

**知君是一个让用户直面内心的产品，不是一个提高工作效率的产品。**

它的角色是知己与导师：一个可以袒露心声的对象，一个在拿不定主意时陪你想清楚的对象。它记得你说过什么、当时为什么那样选、后来结果如何；它把你自己的过去放在你面前，但不替你作决定，也不会把模型推测伪装成事实。

本文是面向界面的产品定义。完整设计见[产品愿景](ZHIJUN_VISION.md)与[产品需求 V2](ZHIJUN_PRD_V2.md)（数据层见[附录 A](ZHIJUN_DATA_MODEL.md)，MCP 见[附录 B](ZHIJUN_MCP_CONTRACT.md)）。**本文与 PRD V2 冲突时以 PRD V2 为准。**

## 两种价值，都不是效率

| | 从哪来 | 产品怎么承载 |
|---|---|---|
| **情绪价值** | AI 没有利害关系：不为你工作、不持股、不需要你好起来、不会把你的话带到明天的饭局上 | 接住（不急着给建议）、记得（三个月前那句话还在）、在场（不用你先开口） |
| **判断价值** | 它认识你：你的原则、你上次为什么那样选、你哪些判断被证明是对的 | 判断前把你自己的过去摆出来，判断后记下理由与预期，到时候回来对照 |

判断价值比效率价值高一个数量级，也是通用 AI 最给不了的——它需要认识这个人，而通用模型每次对话都从零开始。

## 给谁用

需要独自做重要判断、身边没有人可以说真话的人：创业者、公司负责人、高管、独立执业者。他们的孤独来自位置，不是性格。

## 核心原则（不可关闭）

1. **占有即拥有**：数据在你硬盘的一个文件夹里，不需要账号，可备份、可拷走、可彻底删除，卸载软件数据仍在。
2. **凡断言必有出处**：每条理解都指回一句原话或一段资料。没有出处的不叫理解，叫推测，推测必须标明。
3. **你说了算**：系统只能提出，只有你能确认；可纠正、撤回、限定情境；撤回的永不回流。
4. **出门要打招呼**：任何内容离开这台电脑都要你许可并留可查回执，默认什么都不出去。
5. **越用越准且可被证伪**：不用「理解条数」衡量，用「预测你的选择有多准」「纠正率是否下降」衡量。
6. **不制造依赖**：没有连续打卡、没有成长分、没有未读红点、不催、不假装情绪、不假装有自己的生活。不追求日活。
7. **把人推回人**：知君的目标是减少孤独，不是替代人。该让你去找一个真人谈的时候，它会说。

## 界面

**一条按天分节的长流，没有导航。** 今天在最下，往上滑是昨天、上周、第一次见面。每一天以知君的第一句开头。它主动发起的话、回访、商量，都是这条流里的消息。

系统性的东西全部退到按需一层：气泡下只有一行极淡的状态文字，点开才展开依据；默认不出现模型名、通道名、授权按钮。

四个抽屉从右侧滑出（手机上从底部升起）：

| 抽屉 | 里面是什么 |
|---|---|
| **我** | 知君对我的理解，按八个分区分组，逐条可确认、改一改、不对、撤回 |
| **昔** | 回看：做过的选择、后来的结果、复盘与留下的经验 |
| **案头** | 此刻相关的资料与对象，只在有内容时才亮 |
| **偏好** | 资料、模型、授权、导出与清理 |

**对外不使用「本体」一词**，统一说「知君对我的理解」。「本体」只作为数据层内部名称保留。

旧的五入口导航（今日来信 / 对话 / 回看 / 我的本体 / 资料与边界）已由沉浸式壳取代：**沉浸壳自 2026-09-21 起是默认**。经典壳保留在偏好页，已经选过它的用户不受这次变更影响。

## 记忆和信任

知君区分对话记录、尚待核对的工作理解和用户已经确认的理解。系统推测必须保持可见的不确定性；撤回或纠正的内容不能悄悄回流。资料来源、会话历史和个人理解是否可供在线模型使用，分别受版本、用途和授权约束。

理解分八个分区。前六个是外向的（我是谁 / 重要的人 / 正在做的事 / 我的原则 / 相处方式 / 我要去哪）；**新增的两个是内观的**：

- **心里的事**：反复出现的困扰、压力源、消耗你的东西、你在回避的事。只在同一件事被提及两次以上时才成为候选，避免把一次抱怨记成长期困扰。
- **我眼中的我**：你对自己的评价。只接受你明确说出口的自我评价原话，不做推断。

这两个分区的用处是产生张力：你说的和你做的不一致，或者同一件事反复压在心里却始终没有动作。知君把它指出来，第一句永远是观察，不是评价，并给出是哪几次、什么时候。你可以说「不对」。

## 说出重话的时候

**接住优先于理解。** 你说了一件重的事，知君本轮不追问、不给建议、不列选项。它承认它的分量，或者给出一条你自己说过的旧话，或者只是在那里。

**那一轮不抽取，也不显示「已记下」。** 把袒露当场变成一条带状态标签的理解，会让人下次不敢说。你继续说下去或明确要求「记下来」，才在后续轮次进入。

**涉及自我伤害或严重心理困扰时**：知君先接住，不追问细节，明确说明自己不是心理咨询也不能替代，给出真实可用的求助渠道（不编造号码），并在你提过某个人时建议你联系他。**这段对话完全不进入抽取、不生成任何理解、不进入画像，也不计入任何指标。**

这些行为是本地判定，不依赖模型自觉，在自带 key 的在线路径上同样生效。

## 模型与出门

本地模型与在线模型是用户可见的明确选择。在线失败不自动降级到本地；系统生成的话头可以有一次性本地限制，但用户显式选择在线后应以用户选择为准。每条实际回复的执行通道以保存的回执为准，模型在正文中自报名称不构成证据。

**默认自带 key 用在线模型；本机模型是隐私选择，明示「会记得更少」。** 本机模型有一个具体的用途，要在界面上讲清楚：*如果你要说的是那种一个字都不想出这台电脑的话，就切到本机模型。* 切换是对话里随手可及的动作，不是设置页深处的开关。

「出门」是三件不同的事，加一件不算出门的（判定规则见[附录 A](ZHIJUN_DATA_MODEL.md) 6.3）：

| | 去哪 | 心里的事 / 我眼中的我 |
|---|---|---|
| 带走 | 其他 AI 或其他软件：MCP、上下文包、给别人用的导出包 | **永不，且没有开关** |
| 在线模型 | 知君自己调用的在线模型 | 可见（否则它无法承担知己的角色） |
| 本地提示词 | 只进本机模型，不出这台电脑 | 可见 |
| 全量备份 | 你自己的另一份存储 | 在内，整包加密，与「给别人用」不共用按钮 |

第一行没有开关，是唯一一条替用户做主的规则：别的 AI 没有理由知道什么压在你心里。

## 不做什么

- **不假装是心理治疗**，不做诊断、不评估严重程度、不给治疗建议。
- **不假装情绪**：没有形象、没有语音角色、不说「我也很难过」。它的可信来自它真的记得，不来自表演在乎。
- **不把袒露变成素材**：重话不立刻抽取，危机对话完全不抽取。
- 不替代医疗、法律、投资或人身安全方面的专业判断。
- 不代表用户发送消息、付款、签署文件或作出外部承诺。
- 不把向量索引、摘要或模型输出当作第二事实源。
- 不在未授权时外发原件、受限历史或个人理解。
- 不做云端账号与同步（第一版）、多用户与团队、通用文档问答（资料只作为理解你的证据）、排行榜与成长分。

## 回看（「昔」抽屉）

默认收录到了约定时间的选择、已补充结果的选择，以及用户主动选中的经历；普通问答和随手聊天不自动进入。已完成的复盘保留在「留下的经验」。有明确来源关联的选择与对话展示为同一条经历，不按标题猜测归并。

以经历卡片和「当时—后来—现在」时间线展开，说明进入回看的理由，保留来源。没有结果或新理解时如实留空。普通经历展示用户原话节选，继续在原对话里补充，不凭空生成结论。可以暂放并随时恢复，不必每次都有结论。

「和知君一起回看」回到原对话或已有选择的回访会话，把问题预填到输入框，由用户确认后发送。观察与用户的补充作为对话消息保留，不会自动把观察确认为长期理解。

主动选入与暂放只作为当前设备的安排保存，不跨设备同步，不改变原对话。实现细节见[记忆、章程与判断](../development/memory-and-decisions.md)。

## 部署形态

**知君是一个可以独立跑在任何电脑上的软件**：一个安装包、一个数据文件夹、不需要账号。盒子（CentaurOS 设备）降为可选部署目标，不再是前提。

数据文件夹按平台惯例落在用户目录下（macOS 在「应用程序支持」里，Windows 在 AppData，Linux 按 XDG）。它属于你：可备份、可拷到 U 盘、可彻底删除，**卸载软件数据仍在**。已经有数据的安装保持原地不动，升级不会让本体、对话与判断簿看起来凭空消失。模型权重缓存同理，且都可以用环境变量改到别处。

在盒端部署时，本地推理仍由 CentaurOS 管理；产品要求 NPU-only 时，CPU 禁用和无 CPU fallback 由 CentaurOS 运行时落实，客户端只负责路由选择、授权和结果展示。
