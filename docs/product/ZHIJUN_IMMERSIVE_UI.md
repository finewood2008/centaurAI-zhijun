# 知君「沉浸式 · 拟人化」界面

版本：2026-09-18 · 状态：第一阶段实施中（分支 `redesign/memory-v3`，`?shell=immersive` 开关；稳定后成为默认）

## 1. 为什么

负责人判断：产品要更拟人化；目前展示的东西太多太复杂；用户希望一种更沉浸的交互。盘点实证：对话页一轮里可见 24 类界面元素，15 类是系统性的（模型、授权、出处、整理状态、工作台）；设置页全部是系统信息；本体页以信任态与层级语义为主。信息是按功能分页摆放，不是围绕一个人展开。

拟人化不是让模型像人一样说话，而是让用户感到对面有一个**在场的、连续的、有分寸的存在**。记忆系统 V3（核心画像、求知引擎、开场白、主动发起）是地基，这份文档解决呈现。

## 2. 五个拟人化方向

1. 在场感：知君有状态，可见但不喧哗。在听（你打字时印章微微呼吸）、在想（生成时印章呼吸、段落逐段浮现）、在整理（一行小字）、在等你（安静）。
2. 连续感：界面用时间组织一切。今天在最下，往上滑是昨天、上周、第一次见面；每一天以知君的第一句开头。
3. 一种声音：第一人称、短句、具体、承认不确定；有自己的关注点；固定的小仪式：早晨一封信、晚上一句回看、周日一次回顾、认识第 N 天。
4. 记忆外显但克制：记下什么，用一枚小印「记」在气泡边亮一下（系统做的，不是模型自称），点开才见细节；说「不对」印就撤。
5. 有分寸的边界：不假装情绪、不假装有生活；系统性的东西退到按需一层。

## 3. 界面：一条长流，四个抽屉

- **舞台**：全屏米纸，没有侧栏、导航、工具条。中央是一条按天分节的对话长流：日头（「今天 · 9月18日 周四」）、当天第一条是知君的来信、然后是当天所有对话（用户发起的、知君发起的、回访、商量都在同一条流里）。往上滑加载更早的日子。
- **上方一行**：左边一枚淡淡的「知」印与在场一行（在听 / 在想 / 在整理 N 件事 / 今天是我们认识的第 N 天 / 按时段问候；未配置模型或断连时在这里提示）；右边四枚极小的印 **我 · 昔 · 案 · 偏**，点开从右侧滑出抽屉（手机上从底部升起），看完合上，舞台不变。「案」只在此刻有相关对象时才亮。
  - 我：一卷画像。核心画像原文按分区展开，全景图在卷首，逐行可确认、可撤、可补；底部「完整档案」。
  - 昔：时间线。判断、回访、留下的经验、到期的承诺按日期排列；点一条回到那天的对话；到期的判断从这里开回访。
  - 案头：此刻相关的对象。判断草稿、事情与成果、本轮资料、章程、待你点头的理解；知君提到什么，什么就在这里。
  - 偏好：关系设置（含知君主动找我）、记忆整理、模型与隐私、账号与盒子（连接状态）、外部 Agent、高级（运行时管理台、整理状态、经典 / 沉浸切换、回复节奏）。
- **下方**：输入框、一个「+」（资料、语音，以及收进菜单的「整理成判断」「展开分析」）、发送。识别到你在拿主意时，输入框上方出现一行提示。

## 4. 舞台上的一轮对话

- 知君先开口；它的气泡没有头像，只有一枚淡淡的知印，生成时呼吸。
- 四种来源标签留在正文里，颜色语义不变。
- 气泡下一行极淡的状态文字（「参考了你记下的 3 条」），点开才展开回答依据；默认不出现模型名、通道名、授权按钮。需要用户确认的授权仍用弹层。
- 记印：这一轮知君记下的理解，点开是那条理解与「对 / 不对 / 撤回」。留印：这段对话留下的（已确认、等你点头、判断入簿、承诺），点开展开。
- 判断草稿是流里的一张卡（「我们把它记成一个判断？」），也在案头；确认后进时间线。
- 回复按段落浮现，段间 300 到 600 毫秒停顿，先出第一句；底层流式不变；减少动效偏好或「偏好 → 高级 → 回复节奏」关闭时直通。
- 空状态是一句话：「从眼下在意的事聊起就好。」

## 5. 视觉与动效

米纸底更纯、留白更大；正文 16px、行高 1.7；宋体只用于知君的信与印；朱砂只用于印章与强调。动效只有三种：印章呼吸、段落浮现、抽屉与页面像纸一样淡入淡出。昼夜：按小时给米纸一层极淡的暖或冷色，问候随之变。没有滑动条、徽章、红点。

## 6. 减法清单

侧栏五入口与顶栏 → 无导航，四枚印；今日的关系图与关系时间线 → 我抽屉卷首与昔抽屉；本体页三视图与筛选 → 一卷画像（完整档案仍可从抽屉进入）；回看页三个 tab → 昔时间线；对话页工具条（事情与成果、待核对、整理状态、模型与授权、工作台）→ 案头与偏好按需出现；起手卡 → 知君的开场白；设置平铺 → 偏好抽屉三层。

## 7. 实现要点

- 壳切换在 `src/App.vue`，路由表不变，深链全部保留；`?shell=immersive|classic` 与偏好里的开关。
- 第一阶段不复制对话逻辑：`ConversationPage` 以嵌入模式成为流里唯一可发送的当前块（发送、流式、授权、记忆、产出、草稿原样），历史会话由只读组件渲染；第二阶段再抽 composable 并成为默认，同时改写钉住导航结构的测试。
- 桌面契约不变：未登录、需要连接盒子、写入不确定等状态仍由原槽渲染；`src/immersive/*` 不引入桌面模块，桌面状态经 props 传入。
- 详见 `.claude` 计划与 `docs/development/conversations.md` 的代码入口。
