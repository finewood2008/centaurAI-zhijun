## 一、一个每天都在发生的场景

你在 Claude 里花了二十分钟，把公司的处境、团队的构成、你为什么拒掉上个月那个大客户，全都讲了一遍。它给了你一个很好的建议。

第二天你换到 Cursor 写代码，它不知道你是谁。
下周你用 ChatGPT 想一件事，你又从头讲一遍。
三个月后你换了一家模型厂商，那二十分钟连同后面所有的对话，一起归零。

这不是产品体验问题。这是一个所有权问题：**关于你的那份知识，今天不属于你。**

它属于每一家厂商，分散在它们各自的筒仓里，不可导出、不可审计、不可携带。而 AI 正在从「帮你写点东西」走向「陪你拿主意」。当它开始参与判断，谁掌握关于你的知识，就不再是一件小事。

## 二、知君是什么

**知君是你自己拥有的那份「我是谁」，以及让任何 AI 使用它的接口。**

三句话说清它的结构：

- **对话是输入法。** 你和知君聊天，它把你亲口说的事记下来、把推测标出来请你点头。理解在这里被建立和核对。
- **知识库是资产。** 每一条理解都指回一句原话或一段资料，都有信任状态、有效期、可撤回。它存在你自己硬盘上的一个文件夹里。
- **MCP 是输出口。** 你授权之后，Claude、Cursor、任何支持 MCP 的 AI 都能读到「这个人是谁、在意什么、做过什么判断」。

三者的顺序不能颠倒：先有可核对的理解，才谈得上输出；先有占有，才谈得上拥有。

## 三、一天是什么样的

**早晨七点半。** 你打开知君，它已经在那儿写了一封短信：「昨天你说要在周三前给老周答复，今天周二。另外，上个月你记下的那个『先看数据再拍板』，这周有两次你是当天就定了，是原则变了，还是这两次特殊？」

你回了一句，聊了四分钟。它把新的理解挂在待确认里，你点了两下头。

**上午十点。** 你在 Cursor 里写代码。你没有交代任何背景，但它知道你是一家十二人公司的技术负责人、知道你团队里只有两个人熟悉这套系统、知道你上周决定把测试留在组内做。它给的方案是照着这些来的。你没有做任何事：知君在后台通过 MCP 把这些告诉了它，而且你能看到它读了哪几条。

**下午三点。** 你在纠结一件事，打开知君说「我在考虑要不要接这个单」。它先把你上次拒单的理由放在你面前，然后问了一个问题，最后说了它的看法和前提。你做了决定，它记进判断簿，约好三周后回访。

**晚上十点。** 它说了一句：「今天那件事，后来怎么样了？」你说了两句。它没有追问。

**三周后。** 它回来问结果。结果和你当时的预期不一样。它把当时的理由和现在的结果并排放着，问你哪一条理解需要改。你改了一条。**它比三周前更准了一点，而且这件事有据可查。**

## 四、为什么必须是一个本地独立软件

因为拥有的前提是占有。

如果知君跑在我们的云上，我们就只是又造了一个筒仓：一个你同样带不走、审计不了、换家就归零的筒仓。那样我们解决的是「跨工具」的麻烦，没有解决「不属于你」的问题，而后者才是真问题。

所以：一个安装包，一个数据文件夹，不需要账号。你可以把那个文件夹拷到 U 盘上，可以备份，可以彻底删除。卸载软件，数据还在。模型用你自己的 key，或者完全本地跑。我们看不到你的任何内容：不是因为我们承诺不看，而是因为**我们根本没有副本**。

这条约束同时是产品设计的第一性原则，也是我们和所有云端记忆产品的根本分野。

## 五、为什么是现在

三件事刚好同时发生：

1. **MCP 正在成为事实标准。** 一年前，「把你的上下文给任何 AI」需要为每个工具做一次集成。现在只需要一个协议。输出口第一次有了标准答案。
2. **模型可以自带。** 用户用自己的 key 调最好的模型，或者在本机跑一个够用的小模型。一个不碰用户数据的软件，第一次能提供不打折的智能。
3. **AI 开始进入判断场景。** 写文案的时候，AI 不懂你只是效率损失；帮你想清楚要不要接这个单的时候，AI 不懂你就是给错建议。痛感从「烦」变成了「不敢用」。

再早两年，这个产品做不出来；再晚两年，位置会被占掉。

## 六、我们已经有什么

这不是一份从零开始的设想。当前代码里已经跑通的东西：

- **一套有纪律的记忆系统**：六个分区、四层来源标签（你告诉我的 / 资料里看到的 / 我推测的 / 你想成为的）、四种信任状态、每条理解都带证据与有效期、撤回的永不回流、整合器会让矛盾的理解衰减。这些不是设想，是可运行的代码与测试。
- **一页核心画像**：确定性生成、不调模型、每轮对话都带着它，外发时按预算裁剪并过滤敏感内容。
- **一个会主动开口的知君**：它知道自己不知道什么（缺口、过期、张力、未了结），有节律地主动找你，并且随时可以让它三天别来。
- **一个沉浸式的界面**：没有导航，一条按天分节的长流，系统性的东西全部退到按需一层。
- **一个几乎无依赖的运行时**：现役开发环境不带深度学习框架，547 MB 就能跑完整的对话与理解流程。这对「装到任何电脑上」是决定性的数字。

差距也很清楚：今天的版本依赖一台盒子和一套云端账号体系，MCP 那条路还没有真正打通。**这份愿景要做的事，本质上是把已经长好的核心从它的壳里取出来，装进一个任何人都能双击运行的软件。**

## 七、护城河

1. **数据在用户手里。** 平台可以收回接口，收不回用户硬盘上的文件夹。用得越久，迁移成本越高，而这个成本是用户自己的资产，不是被锁定的代价。
2. **证据链与信任状态是纪律，不是功能。** 外形可以被抄，「每条理解都指回一句原话、推测必须标明、撤回的永不回流」这套约束抄不了，它要求产品在无数处克制自己。
3. **检验闭环。** 知君会在你做决定前写下它的预期，结果回来后对照。这让「越来越懂你」从一句营销话变成一个可以证伪的数字，也是任何云端记忆产品都不愿意做的事。
4. **生态位。** 一旦成为某个人的默认记忆源，每多接一个 AI 工具，它的价值就增加一次，而替换成本要乘以工具数量。

## 八、商业模式：三个选项

| 方案 | 怎么收 | 适用条件 | 风险 |
|---|---|---|---|
| **A 一次性买断** | 软件 299–599 元买断，含一年更新；用户自带模型 key | 目标人群是愿意为工具付费的专业用户；产品是本地软件，无持续服务成本 | 现金流不连续；重大版本需要再次说服 |
| **B 订阅制（含模型代理）** | 每月 30–60 元，我们代理模型调用，用户不用自己找 key | 降低门槛，收入连续 | **与「我们没有你的副本」正面冲突**：代理调用意味着内容过我们的服务器。这会伤害第一性原则 |
| **C 开源内核 + 付费增值** | 内核开源免费，付费项是同步、多设备、团队共享、托管备份 | 建立信任与生态最快；开发者人群天然接受 | 增值项多半要联网，同样触碰隐私叙事；开源后差异化靠执行力 |

**推荐 A 起步，为 C 留门。**

理由：A 与产品的第一性原则完全一致，讲得清、守得住，「你付一次钱，买下一个属于你的软件」本身就是产品主张的一部分。切入人群（每天用多个 AI 工具的专业用户）对买断制接受度高，且他们本来就有模型 key。B 的经济模型更好看，但它要求内容流经我们，会在第一天就把最锋利的那句话磨钝，不建议在早期采用。C 作为中期选项：当 MCP 生态成熟、需要靠分发取胜时，开源内核 + 端到端加密的可选同步是自然的第二步，而且那时「我们看不到内容」可以用密码学而不是承诺来保证。

定价的另一个锚点：用户为 Claude 和 ChatGPT 每月付出的钱，是知君的几倍。我们不与模型争预算，我们让那笔预算更值。

## 九、风险与我们不做的事

**风险**

| 风险 | 对策 |
|---|---|
| 抽取质量决定一切，本地小模型达不到 | 默认自带 key 用在线模型；本地模式明示「会记得更少」，不假装等价 |
| 打包与跨平台是硬工程 | 核心发行版不带深度学习依赖（547 MB 已验证），向量检索作为可选增强包 |
| MCP 生态还早，客户端有限 | 同时提供导出包与剪贴板上下文；MCP 只是适配器，标准若变就换适配器 |
| 冷启动：没有数据时它不懂你 | 建档对话 + 导入双通道；第一次十分钟以「另一个 AI 突然懂你」收尾 |
| 一次隐私事故就失去全部信任 | 默认什么都不出去；逐源授权；回执可查；敏感永不外发；密钥存储方案必须对用户说清楚 |

**我们不做**：云端账号与同步（第一版）；代表用户行动（不替你发消息、不替你付款）；多用户与团队；通用文档问答（资料只作为理解你的证据）；数字人与情绪扮演；任何硬件依赖。

## 十、一句话

**让每个人拥有一份可核对、可携带、只属于自己的「我是谁」，并让任何 AI 在获得许可后使用它。**

产品的成败，不看它一天被打开多少次，看两件事：**它对你的理解有没有越来越准，以及别的 AI 有没有真的用上它。**
