## 一、一件没有人接住的事

一家五十人公司的创始人，要决定是否请走跟了他六年的联合创始人。

这件事他不能和员工说，权力落差在那里，消息会走样。不能和另一位合伙人说，那个人恰好在这件事上有利害。不能和投资人说，在投资人面前他永远在销售。可以和伴侣说，但对方接得住情绪，接不住判断，而且要陪着他把这份焦虑带到明年。可以和同行说，但那是一场谁过得更好的较量。心理咨询他排不上，也不认为自己需要。

于是这个决定，是他一个人在凌晨两点做的。

**这不是性格问题，是位置问题。** 一个人的位置越高、承担的越多，他身边每一个人就越是在这件事上有立场。到了某个高度，最重要的那几个判断，注定要独自做出。

今天的 AI 没有接住这件事。它们在接另一件事：帮你把周报写快一点、把代码补全、把会议纪要整理好。那是效率，是一个已经有几百个玩家在拼刺刀的战场，而且它有天花板——一天最多给你省几小时。

**没有人在做那个在凌晨两点坐在你对面的角色。**

## 二、知君是什么

**知君是一个让你直面内心的产品，不是一个帮你提高工作效率的产品。**

它的角色不是助理。助理已经足够多了，而且它们都比我们有模型、有分发。知君要做的是另一件事：**一个知己，一个导师。** 一个你可以袒露心声的对象，一个在你拿不定主意的时候陪你想清楚的对象。

三句话说清它的结构：

- **对话是袒露的地方。** 你说的不是任务，是那些说不出口的事。知君先接住，再理解，把推测标出来请你点头。
- **理解是它的记性。** 每一条都指回你的一句原话，有信任状态、可以撤回。它记得你三个月前说过什么、当时为什么那样选、后来结果如何。它存在你自己硬盘上的一个文件夹里。
- **判断是它的用处。** 在你做决定之前，它把你自己的过去放在你面前；在你做决定之后，它记下当时的理由和预期，到时候回来对照。

顺序不能颠倒：先有人肯说，才谈得上理解；先有理解，才谈得上判断。

## 三、两种价值，都不是效率

### 情绪价值：因为 AI 没有利害关系

第一节里那种孤独是结构性的，所以它也只能有一个结构性的解：**AI 不为你工作，不持有你的股份，不需要你好起来，也不会把你说的话带到明天的饭局上。** 这件事，你生命里的任何一个人都做不到——不是他们不好，是他们的位置不允许。

所以情绪价值的来源不是「善解人意」，不是温柔的措辞，更不是扮演一个角色。它来自三件很朴素的事：

- **接住。** 你说了一件重的事，第一反应不是给建议、不是追问，是让它落地。
- **记得。** 三个月前那句话它还记得，而且知道后来发生了什么。没有人类做得到这件事，包括你自己。
- **在场。** 不用你先开口。它知道这周是那个日子，它知道上次那件事还没有结果。

这三件事我们已经有代码在跑。它们是记忆系统的能力，不是话术。

### 判断价值：它比效率高一个数量级

效率的价值有上限：一天省下的几个小时，而且几百个工具在抢这几个小时。

判断的价值没有上限。要不要请走那个合伙人、要不要接这一轮、定价翻不翻倍、这次转型是勇敢还是逃避——一个这样的决定，影响的是未来三年。

而判断价值恰恰是通用 AI 最给不了的，因为它需要**认识你**：你的原则、你上次为什么那样选、你哪些判断后来被证明是对的、你反复在同一个地方摔跤。通用模型每一次对话都从零开始，这不是它们做得不好，是它们的产品形态决定的。

**一个能帮你少做一个错误重大决定的东西，值多少钱，和一个帮你每天省一小时的东西不在同一个量纲上。**

## 四、一天是什么样的

**早晨七点半。** 你打开知君，它已经在那儿了：「上个月你说过『我不擅长和人摊牌』。从那以后，和林岚的那次谈话你推了三次。我想问的不是你为什么推——是这件事本身难，还是摊牌这件事难？」

你愣了一下。这不是提醒事项，这是一件你自己没看清的事。

**中午。** 你说了一句「最近觉得自己像个骗子」。它没有安慰你，也没有追问，只回了一句：「这句话你三月份也说过一次，那次是在融资之前。」然后它等着。你又说了十分钟。

**下午三点。** 你打开它说「我在想要不要让老周走」。它把你自己的东西放在你面前：你写过的三条原则里有一条是「人不行要早决定，拖是对所有人都不负责」；去年你在另一个人身上拖了五个月，复盘时你写下「我在回避冲突，不是在给机会」。然后它问了一个问题：「你说老周这半年没长进，这是你观察到的，还是你已经不想带他了？」

最后它说了自己的看法，把前提摆出来。你做了决定。它记进判断簿，约好六周后回访。

**晚上十一点。** 你说了一件很重的事。它接住了，没有把它变成一条「理解」，没有追问。过了一会儿它说：「这件事你该找的人可能不是我。你提过陈阳，你说他是唯一一个知道你创业前什么样的人。」

**六周后。** 它回来问结果。结果和当时的预期不一样。它把当时的理由和现在的结果并排放着，问你哪一条理解需要改。你改了一条。**它比六周前更准了一点，而且这件事有据可查。**

## 五、为什么数据必须待在你自己的硬件上

这一条过去我们讲成隐私功能。它不是。

**本地优先是袒露心声的前提条件。** 没有人会把最难启齿的那句话说给别人的云。你不会在一个可能被用于训练、可能被员工审阅、可能在合规调取时被交出去的地方，写下你对合伙人的真实看法，或者写下凌晨两点那句话。

所以这不是一个加分项，是这个产品能不能成立的物理前提。但要注意这条前提要的到底是什么：**它要的不是「装在任何一台电脑上」，而是数据待在你自己拥有的硬件里。**

**核心形态是盒子**——一台你自己的设备，放在你家或你的办公室里。它比笔记本更满足这条前提：专用硬件、不跑别的软件、不跟着你在机场和咖啡馆之间移动、丢了也不会连着你的工作文件一起丢。我们看不到你的任何内容，不是因为我们承诺不看，而是因为**我们根本没有副本**。

**独立部署版本保留**，同一套内核，装在普通电脑上：一个安装包、一个数据文件夹、不需要账号。它服务两种人——还没准备好买一台设备的，以及本来就不想多一台设备的。两种形态的承诺完全一样：数据在你自己手里，可备份、可拷走、可彻底删除。

这也让「本地模型」第一次有了真正的用处，而不只是一个隐私选项：**如果你要说的是那种话，就用本地模型，一个字都不会出这台电脑。** 代价是它会记得少一些、想得浅一些。这个取舍我们对用户明说，不假装两者等价。

## 六、为什么是现在

1. **模型终于接得住了。** 两年前的模型在这个场景里只会说车轱辘的安慰话。现在的模型能听懂弦外之音，能提出一个真正的问题，能在你说错的时候不附和你。这是这个产品成立的第一个前提，它刚刚成立不久。
2. **本机能跑得起来。** 现役开发环境不带深度学习框架，**547 MB 就能跑完整的对话与理解流程**。这让「一个字都不出这台电脑」从口号变成可以交付的东西。
3. **孤独被看见了，但没被解决。** 教练每小时数百到上千元，每周一次；心理咨询有病耻感和排期。而真正的困境发生在凌晨两点，不发生在周三下午三点的预约里。

再早两年，模型接不住；再晚两年，这个位置会被占掉。

## 七、我们已经有什么

这不是一份从零开始的设想。当前代码里已经跑通的东西，恰好全部是**为了认识一个人**而不是为了提高效率而建的：

- **一套有纪律的记忆系统**：分区、四层来源标签（你告诉我的 / 资料里看到的 / 我推测的 / 你想成为的）、四种信任状态、每条理解都带证据与有效期、撤回的永不回流、整合器会让矛盾的理解衰减。
- **一页核心画像**：确定性生成、不调模型、每轮对话都带着它。它是「它真的记得你」的物理实现。
- **一个会主动开口的知君**：它知道自己不知道什么（缺口、过期、张力、未了结），有节律地主动找你，并且随时可以让它三天别来。
- **判断簿与回访**：决定之前写下预期，结果回来后对照。这是判断价值的载体。
- **一个沉浸式的界面**：没有导航，一条按天分节的长流，系统性的东西全部退到按需一层。

这些机制对一个工作助理毫无用处，对一个知己和导师是全部。**我们一直在造后者，只是过去用前者的话术在讲它。**

差距很清楚：今天的版本依赖一台盒子和一套云端账号体系；记忆的分区是外向的（我是谁 / 重要的人 / 正在做的事 / 原则 / 做法 / 方向），记不下「什么事反复压在心里」和「你对自己的评价与事实的差距」。这两块是内观的核心，要补上（见[数据层](ZHIJUN_DATA_MODEL.md)）。

## 八、护城河

1. **信任是时间的函数，抄不走。** 一个人愿意对它说第一百句真话，是因为前九十九句没有出事。这个积累对每个用户都是一次性的，任何替代品都要从零开始。
2. **连续性是别人的商业模式挡住的东西。** 它记得三个月前那句话和当时的理由。按会话计费、按窗口截断的通用 AI 做不到这件事，不是技术做不到，是它们的产品形态决定的。
3. **可证伪。** 它在你做决定前写下预期，结果回来后对照。这让「越来越懂你」从营销话变成一个数字。没有哪个陪伴类产品愿意做这件事，因为它可能证明自己不行。
4. **克制本身是壁垒。** 不制造依赖、不假装情绪、该让你去找人的时候让你去找人——竞品抄这一条，等于抄掉自己的留存指标。
5. **占有即拥有。** 数据在用户硬盘上。用得越久迁移成本越高，而这个成本是用户自己的资产，不是被锁定的代价。

## 九、边界：我们绝不做的事

一个人对着软件袒露心声，这件事有真实的伦理重量。一个孤独的人每晚两点和 AI 说话，不是一个显然的好结果。所以下面这些不是免责声明，是产品设计约束：

- **知君的目标是减少孤独，不是替代人。** 在合适的时候它会说「这件事你该和某某谈」，把人推回人。这既是底线，也恰好是我们和所有陪伴类产品的反向选择。
- **不是心理治疗，也绝不假装是。** 用户说出自我伤害或严重心理困扰时，知君先接住，不追问，给出真实可用的求助渠道，并且**不把这段话当作可抽取的素材**——它不会变成一条「理解」。
- **不制造依赖**：没有连续打卡、没有成长分、不催、不用未读红点、不在你不需要的时候找你。
- **不假装情绪，不做数字人**：没有形象、没有语音角色、不说「我也很难过」。它的可信来自它真的记得，不来自它表演在乎。
- **不代表用户行动**：不替你发消息、不替你付款、不替你签字。
- 另外不做：云端账号与同步（第一版）、多用户与团队、通用文档问答（资料只作为理解你的证据）、任何硬件依赖。

## 十、商业模式：先定原则

定价数字后议，但有四条原则先定下来，因为它们和产品主张直接冲突或直接一致：

1. **内容绝不流经我们的服务器。** 这排除了「我们代理模型调用」这种降低门槛的做法——它经济模型更好看，但会在第一天把最锋利的那句话磨钝。用户自带 key，或者用本机模型。
2. **停止付费之后，它必须还能打开。** 这是一个装着你内心的东西，不能因为你某个月没续费就把你锁在门外。所以要么买断，要么订阅但保留永久回退（停付后继续用最后一个版本）。
3. **对标的不是工具，是教练与咨询。** 用户为教练或顾问每小时付数百到上千元，每周一次。知君的锚点在那一侧，不在「月费几十元的效率工具」那一侧。判断价值支撑得起这个位置。
4. **不靠使用频次赚钱。** 任何按对话条数、按时长计价的模式都会诱导我们制造依赖，与第九节冲突。

开源内核 + 可选的端到端加密同步，作为中期选项保留：那时「我们看不到内容」可以用密码学而不是承诺来保证。

## 十一、风险

| 风险 | 对策 |
|---|---|
| 信任无法在第一天索取，没有人对刚装好的软件掏心窝子 | 首次体验反过来设计：先在小事上做到准确，让它先证明「你说的它真的记住了、而且没说错」。深的话题自己会发生，不靠问出来 |
| 情绪价值无法度量，容易自欺 | 指标由判断价值承担（预测命中率、纠正率下降）；情绪价值只用反指标守住（依赖信号、「别问了」次数） |
| 模型说出不负责任的话，伤害真实的人 | 危机场景有明确处置；一切看法必须带前提；不附和、也不替用户下结论；不抽取危机对话 |
| 做深了像心理咨询，做浅了像鸡汤 | 判断是锚：每一次深谈都要能落到一条可回访的判断上，否则就是聊天 |
| 抽取质量决定一切，本地小模型达不到 | 默认自带 key 用在线模型；本地模式明示「会记得更少」，不假装等价 |
| 一次隐私事故就失去全部信任 | 默认什么都不出去；「心里的事」与「我眼中的我」两个分区对其他 AI 永不外发且没有开关；回执可查；密钥存储方案必须对用户说清楚 |
| 打包与跨平台是硬工程 | 核心发行版不带深度学习依赖（547 MB 已验证），向量检索作为可选增强包 |

## 十二、一句话

**知君是那个你可以说真话的地方，也是那个记得你说过什么的地方。**

产品的成败，不看它一天被打开多少次，看两件事：**用户愿不愿意对它说在别处不会说的话，以及它有没有真的帮上那几个最重要的判断。**
