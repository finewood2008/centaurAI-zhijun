知君 V1

运行在私人记忆盒子上的个人本体 Data Agent：先成为可信的镜子，再成为有边界的良师益友。

DATE 2026-09-01 OWNER 半人马AI TARGET 24周 / 20人邀请Beta
REVIEW
是什么

把零碎资料治理成可核对、可纠正、可持续成长的个人本体，并为其他 Agent 提供最小可信上下文。

服务谁

首发面向企业主与核心决策者：数据敏感、上下文密集、独立决策、单位时间价值高。

为什么现在

现有主仓已经具备采集、解析、检索、问答和治理骨架，可以从个人知识库演进为真正的个人本体。

Problem

高价值用户的数据散落在文档、聊天、录音、照片和脑海里。传统工具能保存或搜索，却不能区分事实、愿望和推测，也不能把一次次判断转化为长期成长。

“把个人日常零碎的数据整理成一个完整的、能够帮助用户实现自我成长的另一个 AI 的自己。”

角色路径

L1 / V1

镜子

L2 / BETA

良师
模式、反向问题、可选建议和行动复盘。

L3 / LATER

分身
未来才允许代表用户表达或行动。

Goals & non-goals

Goals

  • 统一 Source–Evidence–Entity–Claim 权威链
  • 交付首次“被真正理解”时刻
  • 跑通判断–行动–结果–复盘
  • 良师建议有依据、可关闭、可纠正
  • 为万象和 Agent 提供最小 Context

Non-goals

  • 账号自动连接与常开采集
  • 实时语音与数字人
  • 心理治疗或高风险决策替代
  • 代表用户发送或执行动作
  • 团队共享本体

User stories

  • 作为企业主，我想记录判断和依据，以便用真实结果校正自己。
  • 作为长期用户，我想区分现实自我和理想自我，以免愿望被当成事实。
  • 作为资料所有者，我想展开每项理解的出处，并能确认、纠正或删除。
  • 作为万象用户，我想让 Agent 懂我，但不能让它直接读取全部原件。
