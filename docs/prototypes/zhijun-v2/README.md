# 知君 V2 高保真产品原型

这是基于 docs/product/ZHIJUN_PRD_V1.md 从零设计的可交互桌面原型。

## 原型范围

- 今日：唯一下一步、最多三项重要事项、良师观察和系统状态。
- 问知君：事实／推测／建议分层，回答与证据并排，本次出盒预览。
- 我的本体：人物、项目、关系与四层自我，理解可纠正和撤回。
- 成长：人生章程、判断簿、周复盘与小行动实验。
- 待确认：候选理解、冲突、人物消歧和系统推测治理。
- 来源：本地导入、处理状态、版本、证据定位和删除。
- 隐私与设备：出盒台账、Agent 权限、可信设备、导出与删除。
- 全局记录：文字、语音、照片和文件入口。
- 首次建档：隐私解释、人生章程、资料导入、首批确认和第一次被理解。

## 原型说明

- 原型中的人物、公司、项目、资料与判断均为虚构示例。
- 原型不连接真实接口，不读写用户数据。
- 旧产品只提供能力清单；本原型没有复用其信息架构或视觉组件。
- 该原型用于产品评审、用户访谈和后续前端实现对照。

## 关键交互

- 左侧导航切换全部一级页面。
- “记录此刻”打开多模态记录面板。
- 问知君发送问题前展示精确出盒预览。
- 证据编号和“查看全部依据”切换右侧证据内容。
- 成长页可切换周复盘、判断簿、人生章程和行动实验。
- 待确认页可以确认、修正、拒绝或稍后处理理解。
- 来源页可以模拟导入文件并查看本地处理状态。
- 隐私页可以展开一次完整出盒回执。
- 顶部“重看首次建档”进入分步式建档体验。
