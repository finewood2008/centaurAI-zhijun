# 知君 V3 对话式操作系统原型

这是独立于 V2 和生产前端的高保真交互原型。它用虚构数据演示知君如何通过对话推动记录、理解、判断与成长，并把结果沉淀为必须由用户确认的可信对象。

## 启动

在仓库根目录运行：

```bash
python3 -m http.server 8622 --bind 127.0.0.1 --directory docs/prototypes/zhijun-v3-conversation
```

然后打开 <http://127.0.0.1:8622/>。

## 重点体验

1. 在「今日知君」回答远川条款的关键问题，观察右侧判断卡实时变化，展开依据并确认判断、设置回访。
2. 从一级导航进入「本体全景」，筛选四层自我并点击人物、项目、原则或候选节点，查看版本、时间与盒内依据。
3. 在候选节点详情点击「就此和知君校准」，补充合作边界的背景，确认、修正或拒绝知君的理解；确认后再查看节点如何从信任边界外进入本体内环。
4. 在「成长」完成 COO 任命的到期复盘，形成十四日行动实验并回到原议题。
5. 长按任意输入区的「按住说话」按钮，松开后查看转写、编辑与确认状态。
6. 在「数据与边界」查看精确出盒预览、Agent 授权影响和删除影响预览。

## 边界

- 不连接后端，不调用现有 API。
- 不修改 V2、Vue 应用或任何生产代码。
- 所有人物、议题、来源、模型和记录均为虚构示例。
- 原型中的出盒、授权、删除和语音交互仅用于验证产品逻辑。
